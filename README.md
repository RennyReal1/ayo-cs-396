# Google Mira
### Path to Conversion Insights

Google Mira is an enterprise marketing analytics web dashboard for multi-channel attribution, customer journey analysis, and AI-powered conversion insights.

## Features

- **Customer Journeys**: Searchable, sequential user touchpoint timelines with multi-touch interaction tracking.
- **Attribution Analysis**: Algorithmic attribution modeling comparing First-Touch, Last-Touch, Linear, and Position-Based (40/20/40) credit shares.
- **Channel Performance**: Detailed breakdown of acquisition channels across Discovery (First Touch), Nurturing (Middle Touch), and Closing (Last Touch) roles.
- **Audience Insights**: Behavioral comparisons of converting vs. non-converting audiences by journey length and channel diversity.
- **AI Recommendations**: Strategic recommendations generated by Gemini based on conversion velocity and channel synergies.
- **Reports**: Executive scorecards with CSV data export.

## Tech Stack

- React 18 + Vite + TypeScript + Tailwind CSS
- Firebase Firestore (`p2c_touchpoints` collection)
- Google GenAI SDK (Gemini)
